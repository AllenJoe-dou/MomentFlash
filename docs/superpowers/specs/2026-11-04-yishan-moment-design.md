# 一闪 Moment 产品设计规格

日期：2026-11-04
状态：已确认，待用户审阅后进入实现

## 1. 产品目标

“一闪 Moment”是一个可部署到 Railway 的轻量互动页面。操作人员可配置顶部图片、动态背景、文本栏和选项栏；参与者可选择预设图片或上传自己的图片、选择选项并填写自由文本；提交后，操作人员可在管理页面查看全部内容。

当前阶段先实现本地演示版，不引入数据库。验证通过后再部署至 Railway。

## 2. 范围

### 2.1 参与者页面

路径：`/`

包含以下区域：

1. 顶部图片展示框
   - 支持点击或拖拽上传图片。
   - 支持从预设图片中选择。
   - 上传或选择后立即显示预览。
   - 图片展示框使用圆角、描边、阴影和轻微玻璃反射效果。

2. 动态背景
   - 页面默认使用粉色梅花飘落背景。
   - 提供四种可切换背景：
     - `pink-plum`：粉色梅花飘落
     - `violet-flow`：蓝紫色流光玻璃
     - `golden-hour`：暖金色夕阳玻璃
     - `ocean-bubble`：深海蓝气泡玻璃
   - 所有背景均采用 CSS/Canvas 动态视觉，不依赖外部视频。
   - 背景切换后立即生效，并保存在当前会话中。

3. 文本栏与选项栏
   - 文本栏允许参与者输入任意文字。
   - 选项栏支持单选和多选。
   - 参与者可直接点击选项完成选择。
   - 页面必须清晰展示必填与选填状态。

4. 提交按钮
   - 提交前校验必填内容和已上传/已选择的图片。
   - 提交成功后显示确认反馈，并允许继续查看当前内容。
   - 演示版提交记录保存到本地 JSON 文件。

### 2.2 操作人员管理页面

路径：`/admin`

功能：

- 查看全部提交记录，按提交时间倒序显示。
- 每条记录展示：
  - 提交时间
  - 图片来源（预设或上传）
  - 上传图片预览（如有）
  - 所选背景
  - 所有文本栏回答
  - 所有选项栏选择
- 支持按关键词筛选提交内容。
- 支持将提交记录导出为 CSV。
- 演示版暂不设置登录系统。

### 2.3 操作人员配置页面

路径：`/admin/edit`

功能：

- 编辑页面标题与说明。
- 设置预设图片列表。
- 上传默认图片。
- 选择默认背景。
- 添加、删除、排序文本栏。
- 添加、删除、排序选项栏。
- 设置每个文本栏/选项栏的标题、提示文字、是否必填。
- 选项栏可设置为单选或多选。
- 保存后参与者页面立即使用新配置。

## 3. 技术方案

采用 Node.js + Express 单体应用。

### 3.1 文件结构

- `server.js`：Express 服务、API、静态文件托管
- `public/index.html`：参与者页面
- `public/admin.html`：提交记录管理页面
- `public/admin-edit.html`：操作人员配置页面
- `public/styles.css`：液态玻璃视觉、响应式布局、动画
- `public/app.js`：参与者交互
- `public/admin.js`：管理页面交互
- `public/admin-edit.js`：配置页面交互
- `public/backgrounds.js`：背景动画系统
- `data/config.json`：页面配置
- `data/submissions.json`：演示版提交记录
- `uploads/`：演示版上传图片
- `README.md`：本地启动、配置、Railway 部署说明
- `package.json`：项目依赖和启动命令
- `Procfile`：Railway 启动命令
- `railway.json`：Railway 配置
- `.gitignore`：忽略本地上传和运行时数据变化中不应提交的内容

### 3.2 API

- `GET /api/config`：读取页面配置
- `PUT /api/config`：保存页面配置
- `POST /api/upload`：上传图片
- `POST /api/submissions`：创建提交记录
- `GET /api/submissions`：读取提交记录
- `GET /api/submissions/export.csv`：导出 CSV

### 3.3 数据存储

演示版使用 JSON 文件：

- `data/config.json` 保存操作人员配置。
- `data/submissions.json` 保存提交记录。
- 上传图片保存至 `uploads/`。
- 服务重启后配置和提交记录仍保留。
- 文件仅适用于演示和小规模测试，不用于正式高并发生产环境。

## 4. 视觉设计

- 主风格：新拟态液态玻璃、柔和渐变、细腻光泽、轻量阴影。
- 配色：
  - 主色：粉色 `#FF5F91`
  - 强调色：紫色 `#8B5CF6`
  - 辅助色：天蓝 `#55C7FF`
  - 文字主色：深灰 `#252333`
  - 玻璃底色：半透明白色与半透明深色
- 字体：中文优先使用系统无衬线字体，确保 Railway 环境无额外字体依赖。
- 响应式：
  - 手机端单列布局。
  - 平板和桌面端内容区居中，最大宽度约 920px。
  - 所有按钮和输入控件支持触摸操作。
- 动画：
  - 梅花以不同大小、角度、速度飘落。
  - 玻璃卡片有轻微呼吸式高光。
  - 背景切换使用淡入过渡。
  - 遵循 `prefers-reduced-motion`，减少动态效果。

## 5. 部署要求

- 支持 GitHub 仓库连接 Railway。
- Railway 通过 `npm start` 启动。
- 默认端口使用 `process.env.PORT || 3000`。
- 不依赖本地绝对路径。
- 上传文件和 JSON 数据位于项目内可写目录。
- README 提供：
  1. 本地安装与运行步骤
  2. 配置编辑说明
  3. GitHub 推送步骤
  4. Railway 部署步骤
  5. 环境变量与数据存储说明

## 6. 验收标准

- 本地执行 `npm install` 与 `npm start` 后，可通过浏览器打开参与者页面。
- 可上传图片并看到即时预览。
- 可选择预设图片。
- 四种背景均可切换，其中粉色梅花飘落背景具有明显动态效果。
- 文本栏和选项栏可根据配置显示并正常填写。
- 必填内容未完成时无法提交。
- 提交成功后，`/admin` 能看到本次提交。
- `/admin` 能筛选和导出 CSV。
- `/admin/edit` 能修改配置，并在参与者页面生效。
- 页面在桌面和手机尺寸下无明显溢出或遮挡。
- 项目可推送至 GitHub，并可由 Railway 正常启动。

## 7. 暂不实现

- 用户登录与权限系统。
- PostgreSQL/Redis 等外部数据库。
- 云图片存储与 CDN。
- 提交后的邮件、微信或短信通知。
- 多语言切换。
- PWA/移动端安装包。
